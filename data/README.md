# data/

This folder is where your raw and intermediate data files go. 

Three files are expected to live here:

1. `tracks.csv` — the public song catalogue with audio features. Download
   from https://zenodo.org/records/11453410 (see the main README for the
   full citation and why this exists).
2. `liked_songs.csv` — your saved songs' metadata, generated by running
   `python -m scripts.export_liked_songs`.
3. `merged_cleaned.csv` — your liked songs merged with the public
   catalogue, generated by running
   `python -m scripts.merge_with_public_catalogue`. This is the file
   `scripts/refresh.py` actually uses.

If you keep any of these files somewhere else, update the matching path
in your `.env` file instead of moving them here.

Note: tracks.csv is too large to commit, and liked_songs.csv is too personal to commit, so it is kept private.
